## Failures and decisions

- Use CUDA 12.8/Torch 2.7.1 for Blackwell and WSL ext4 for case-distinct Linux
  headers. Cost: this measured recipe is specific to the current WSL/GPU setup.
- Materialize Chumpy/SciPy numeric containers with the existing restricted loader,
  retaining originals. This avoids obsolete executable dependencies; it is still
  original FLAME, not Open, and grants no redistribution rights.
- diffusers 0.30.3 silently ignored Q/K norms and generated a distorted head.
  LAM's own `QKNormJointAttnProcessor2_0` fixed CUDA and browser renders. This
  explicit compatibility adapter is required for the pinned dependency.
- Blender 4.4 removed `export_colors`. The small replacement exporter checks
  script exit codes and output files; upstream reported success without a GLB.
- SDK initialization can resolve undefined or before splats load. Readiness now
  waits for completion; failures/timeouts reach the UI. The camera fits the head,
  and unrequested facial controls are held neutral.
- Windows event 1074 records a planned OS upgrade restart at 18:06:45; events
  41/6008 also record an abnormal shutdown. This task executed no reboot command;
  the abnormal shutdown's cause is unestablished. Pending metadata was damaged.
  Metadata/ZIP publication now uses temporary files and atomic replacement. The
  final photo run did not reuse a fit.

The setup recipe mirrors successful installation commands but was not rerun from
a completely clean WSL instance. SDK performance warnings, real-device acceptance
and public/commercial asset rights remain separate follow-ups. Models, photos,
generated packages and passwords are not committed.
