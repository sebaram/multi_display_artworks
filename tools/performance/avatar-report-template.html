검증 범위

이 결과는 Windows PC와 실제 로컬 Socket.IO 연결을 사용한 합성 부하입니다. 390px·4배 main-thread slowdown은 같은 PC의 스트레스 조건입니다. 휴대폰과 Quest의 성능 측정은 NOT_RUN이며, XR 영상은 실제 앱에 가상 입력을 넣은 기능 검증입니다. 원본 화면의 구버전 수치 성능은 측정하지 않았습니다.

인원·거리·작품별 측정

N은 화면에 표시할 원격 합성 방문자 수입니다. 관찰자는 자신의 숨겨진 아바타 한 명을 별도로 계산하므로 연결 수는 N+1입니다. 사람형만의 full/low/hidden 수와 기존 모델·none 수, 실제 거리를 표시합니다. 혼합 모델의 LOD 카운터는 사람형에만 해당합니다. mixed-models는 사람형·기존 도형 로봇·Shiba·RiggedSimple을 순환하며, 사람형 프리셋 네 개는 같은 GLB를 공유합니다.

넓은 표는 가로로 이동할 수 있습니다. 작품 수는 fixture 전체이며 resident는 관찰 시점에 실제 상주한 작품 수입니다. FPS는 main scene renderer.render의 실제 호출 수입니다. frame p95는 그 호출 간격입니다. 함수 p95는 performance.now()로 감싼 동기 구간의 elapsed wall time이며 정확한 OS CPU 시간이 아닙니다. remote active p95는 실제 관절 보간·적용이 있는 프레임만 포함합니다. 두 반복이 있는 행의 FPS·draw calls·traffic은 중앙값, p95·메모리는 더 큰 반복값을 표시합니다. 한 반복인 행은 해당 단일 값을 표시합니다. raw에는 모든 프레임과 반복이 있습니다. pose 도착 지연은 합성 송신 시각부터 관찰자의 CDP 수신 콜백까지이며 CDP/생성기 스케줄링을 포함합니다. legacy v1에는 이 값이 없습니다. 높은 FPS라도 도착 지연이 크면 실시간 동작이 아닙니다. ⚠ >1s는 도착 p95가1초를 넘는다는 보고서의 설명용 표시이며 제품 SLA가 아닙니다. 이런 행도 렌더 반복에 그대로 포함합니다.

네트워크 중계만 따로

아래 N은 렌더러 없이 연결한 실제 Socket.IO 참가자 수입니다. 한 Node 프로세스가 여러 합성 클라이언트를 실행하므로 load generator 포화가 결과에 섞일 수 있습니다. 서버와 생성기의 CPU를 함께 기록했습니다. bytes/s는 압축 해제된 애플리케이션 메시지 데이터의 합계로 WebSocket/TCP/IP 프레임 헤더와 TLS 비용은 포함하지 않습니다. 실제 압축된 wire throughput이 아닙니다. 수신 지연은 같은 PC의 송신 시각부터 수신 콜백까지이며, 화면 보간 지연 100ms와 별개입니다.
